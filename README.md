# Italiano Vokabeltrainer

PWA für italienische Vokabeln mit Leitner-System (5 Kästen).

## Verwendung
1. `index.html` in einem Browser öffnen
2. Auf dem Handy: URL aufrufen, "Zum Startbildschirm hinzufügen"

## Features
- Deutsch → Italienisch (Hauptmodus)
- Italienisch → Deutsch
- Leitner-System mit 5 Kästen
- Vokabeln in der App verwalten
- CSV-Export als Backup
- Offline-fähig (PWA)
- Daten im Browser-LocalStorage
